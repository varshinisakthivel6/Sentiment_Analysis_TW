# Sentiment Analysis Web Application

## 📌 Project Overview
Sentiment Analysis is a web application that analyzes text data and classifies sentiments as **Positive, Negative or Neutral**. It helps identify user opinions from customer reviews, feedback and other text inputs.

## 🎯 Objectives
- Analyze text and identify the sentiment expressed.
- Classify text into positive, negative or neutral categories.
- Understand user opinions and feedback.
- Present sentiment analysis results in a simple and user-friendly way.

## ✨ Features
- Text input for sentiment analysis.
- Sentiment classification into three categories.
- Simple and user-friendly interface.
- Supports analyzing customer reviews and feedback.

## ⚙️ How It Works
1. Enter the text to be analyzed.
2. Submit the text for processing.
3. The application analyzes the input.
4. The result is displayed as Positive or Negative.

## 🚀 Applications
- Customer review analysis.
- Social media opinion analysis.
- Customer feedback analysis.
- Understanding user satisfaction.
